# Barnyard Economist v5 whole-agent hedge

This directory vendors the exact Apache-2.0 Kaggle Version 4 output as an
independent evaluation candidate. It is not a component splice, and the
notebook's grid-search settings are frozen as provenance rather than treated
as public-leaderboard evidence.

Reproduce the both-seat screen and disjoint confirm evaluation with:

```bash
python3 scripts/measure_barnyard_economist.py
```

The measurement performs no Kaggle submission. Promotion requires independent
rank and margin evidence plus non-regressing p20/worst tails.
