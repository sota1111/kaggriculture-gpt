# V16-RC5 portable candidate

This is an independent, self-contained candidate built from `main.py` plus a
clean-room overlay. It is not a partial champion promotion: the repository
champion and `submission.tar.gz` remain untouched, and the packaged candidate
defaults OFF.

The referenced public notebook declares no license in its downloaded metadata
or body. Consequently, its executable, compressed action table, and replay-
reconstructed route are not redistributed. The overlay implements only the
public prose boundaries: the disclosed 8-cattle/4-sheep herd milestones,
inventory-feasible livestock-slot selection, and current-public-state priority
among already-existing premium sale slots.

Build disabled or enabled artifacts with
`python3 scripts/package_v16_rc5_portable.py --output PATH [--enable]`.
The parent SOT-2947 portfolio is the only place allowed to consume confirm.
