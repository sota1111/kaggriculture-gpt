champion in `main.py` and the repository submission archive remain unchanged.

Unlike the previously evaluated v39 sparse-history gate, v19 refreshes a full
four-expert medoid route and adds clone-aware late inventory/collision control.

unseen-team cases. This repository does not ship those replay/private traces;
it evaluates only the Apache-2.0, standard-library output agent on new local
lineage/time-separated closed-loop panels.

The screen and confirm evidence is generated by
`scripts/measure_kaito_v19_replication_control.py`. Promotion, if any, means
only that this artifact remains a default-off independent hedge. No Kaggle
submission is performed by this issue.
