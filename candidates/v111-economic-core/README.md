# V111 8C4S economic-core candidate

This is an independently packaged, default-off whole-agent candidate. The
referenced Kaggle notebook was downloaded at version 1 and hash-pinned, but its
downloaded metadata and body declare no license. Its executable and compressed
replay-derived action table are therefore not redistributed.

The candidate is a clean-room implementation of only the public description:
an 8-cow/4-sheep economic core and inventory-feasible premium-sale ordering.
It is assembled on the separately attributed MIT lonespear whole-agent, never
on `main.py`. Run `python3 scripts/package_v111_economic_core.py --output X`
to produce the single-file offline artifact.

See `source.json` for hashes and the reuse boundary. No Kaggle submission was
made for this candidate.
