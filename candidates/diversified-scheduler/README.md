# Diversified scheduler candidate

This is an independent, dependency-free, default-OFF clean-room candidate. It
assigns each unit at most one unique current-state job, reserves next positions
to prevent movement collisions, and bounds workforce growth at seven hands.

The public notebook snapshot is hash-pinned in `source.json`. Because no license
was declared in its metadata or body, neither its source nor route is included.
The repository champion (`main.py`) remains unchanged as the portfolio hedge.
