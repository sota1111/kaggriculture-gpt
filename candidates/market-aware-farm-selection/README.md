# Market-Aware Farm Selection

This is an independently packaged, default-off, clean-room candidate inspired only by the public description of the pinned Kaggle notebook. The upstream license is unspecified, so upstream source is neither copied nor redistributed. The candidate observes unlocked public shops, selects one coherent dairy, fiber, or produce farm foundation, and retains an end-horizon liquidation guard.

`scripts/measure_market_aware_farm_selection.py` combines the MIT foundation with `adapter.py` in a temporary directory, records policy firing and action traces, runs a same-seed/both-seat screen, and opens the identity/episode/seed/seat/time-disjoint confirm panel only if the screen gate passes. It never changes `main.py`, `submission.tar.gz`, or submits to Kaggle.
